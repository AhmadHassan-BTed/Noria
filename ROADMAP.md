# Roadmap

This document outlines the planned features and improvements for Noria.

## 2.x (Current)

### 2.1 (Q3 2026) - Additional Providers

- [ ] Jobs provider with job-specific scoring
- [ ] Internships provider with internship criteria
- [ ] Grants provider for research grants
- [ ] Fellowships provider

### 2.2 (Q4 2026) - Enhanced Scrapers

- [ ] RSS feed scraper
- [ ] Generic API scraper
- [ ] LinkedIn scraper (if legal/possible)
- [ ] Custom webhook support

### 2.3 (Q1 2027) - Alternative Notifiers

- [ ] Email notifier
- [ ] Slack notifier
- [ ] Telegram listener and notifier
- [ ] Discord notifier
- [ ] SMS notifier (Twilio)

### 2.4 (Q2 2027) - Web UI

- [ ] Configuration dashboard
- [ ] Real-time analytics
- [ ] Pipeline status monitoring
- [ ] Manual opportunity entry
- [ ] Opportunity history/archive

### 2.5 (Q3 2027) - Advanced Features

- [ ] Database integration (PostgreSQL)
- [ ] User profiles and teams
- [ ] Saved opportunities
- [ ] Application tracking
- [ ] Performance analytics

## 3.0 (Future Consideration)

- [ ] Distributed deployment support
- [ ] Cloud-native architecture
- [ ] Machine learning-based duplicate detection
- [ ] Natural language processing for better matching
- [ ] Mobile app

## Under Investigation

- Browser extension for detecting opportunities
- Integration with IFTTT/Zapier
- API endpoint for external integrations
- Machine learning for improved matching
- Blockchain-based verifications

## Community Contributions Welcome

This roadmap is flexible and community-driven. If you want to work on any of these features or propose new ones:

1. Open a GitHub Discussion
2. Check if anyone is already working on it
3. Coordinate with maintainers
4. Submit a PR with your implementation

## Priority Levels

- **High** 🔴 — Core functionality gaps, security, stability
- **Medium** 🟡 — Requested features, nice-to-have improvements
- **Low** 🟢 — Enhancement ideas, future exploration

## Timeline

Timelines are estimates and may shift based on:
- Community contributions
- Bug reports and fixes
- Breaking changes required
- Resource availability
